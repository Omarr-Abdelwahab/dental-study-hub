# Dental Study Hub Backend

This workspace is reserved for the production API and background services.

Before implementation, define:

- API runtime and framework
- PostgreSQL provider and ORM
- Authentication and authorization model
- File and video storage
- Payment provider and webhook processing
- Email provider and background job strategy
- Testing, observability, backup, and deployment requirements

Keeping these decisions explicit prevents the frontend demo's browser-local state from becoming an
accidental backend architecture.
